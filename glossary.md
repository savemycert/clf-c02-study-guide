# CLF-C02 Glossary

## #

- **7 Rs**: The seven per-application migration strategies: rehost, replatform, refactor, repurchase, relocate, retain, and retire.

## A

- **Access keys**: A long-term key ID and secret pair used for programmatic access through the CLI, SDKs, or API.
- **Agility**: The organization's ability to experiment, build, and release quickly because resources are available in minutes.
- **Amazon Athena**: A serverless service for running SQL queries directly on data in S3.
- **Amazon Aurora**: An AWS-built relational engine, compatible with MySQL and PostgreSQL, with storage replicated across three AZs.
- **Amazon CloudFront**: The AWS content delivery network that caches content at edge locations.
- **Amazon CloudWatch**: Monitoring service that collects metrics and logs and fires alarms when a threshold is crossed.
- **Amazon Comprehend**: A natural language processing service that finds sentiment, entities, and key phrases in text.
- **Amazon DynamoDB**: A serverless NoSQL key-value and document database with consistent millisecond latency at any scale.
- **Amazon EBS**: Persistent network-attached block volumes for EC2 instances.
- **Amazon EC2**: Resizable virtual servers (instances) where you control the operating system.
- **Amazon EC2 Auto Scaling**: A service that adds or removes EC2 instances to match demand, delivering elasticity.
- **Amazon ECS**: AWS's native managed service for orchestrating containers.
- **Amazon EFS**: An elastic NFS file system that many Linux instances can mount at the same time.
- **Amazon EKS**: A managed Kubernetes service in which AWS runs the control plane.
- **Amazon ElastiCache**: A managed in-memory data store running Redis or Memcached, mainly used for caching.
- **Amazon EventBridge**: A serverless event bus that routes events to targets based on rules.
- **Amazon FSx**: A family of managed file systems, including Windows File Server and Lustre.
- **Amazon GuardDuty**: Threat detection that analyzes CloudTrail, VPC Flow Logs, and DNS logs to spot malicious or unauthorized activity.
- **Amazon Inspector**: Scans EC2 instances, container images, and Lambda functions for known software vulnerabilities and unintended network exposure.
- **Amazon Kendra**: An ML-powered enterprise search service that answers natural-language questions from internal documents.
- **Amazon Kinesis**: A family of services for collecting and analyzing streaming data in real time.
- **Amazon Lex**: A service for building chatbots and voice bots.
- **Amazon Polly**: A service that converts text to lifelike speech.
- **Amazon QuickSight**: A business intelligence service for dashboards and visualizations.
- **Amazon RDS**: A managed relational database service for engines such as MySQL, PostgreSQL, SQL Server, and Oracle.
- **Amazon Redshift**: A data warehouse for SQL analytics on large volumes of structured data.
- **Amazon Rekognition**: A pre-trained service that analyzes images and video for objects, faces, and unsafe content.
- **Amazon Route 53**: The AWS DNS service, which also registers domains and routes traffic based on health and latency.
- **Amazon S3**: Object storage that holds data in buckets and is accessed over HTTPS.
- **Amazon SageMaker**: A managed platform for building, training, and deploying your own machine learning models.
- **Amazon SNS**: A publish/subscribe service that pushes each message to all subscribers of a topic.
- **Amazon SQS**: A managed message queue from which consumers pull messages, which decouples components.
- **Amazon Textract**: A pre-trained service that pulls text, form fields, and tables out of scanned documents.
- **Amazon Transcribe**: A service that converts speech to text.
- **Amazon VPC**: A logically isolated virtual network in AWS whose IP range you define.
- **Amazon WorkSpaces**: A service that provides persistent virtual desktops in the cloud.
- **Availability Zone (AZ)**: One or more discrete data centers in a Region with independent power, cooling, and networking.
- **AWS Application Migration Service (MGN)**: The main rehost service, which replicates source servers so they run natively on EC2.
- **AWS Artifact**: A free console portal for downloading AWS's third-party audit reports and accepting agreements such as the HIPAA BAA.
- **AWS Audit Manager**: Continuously collects evidence from your accounts and maps it to control frameworks to prepare for your own audits.
- **AWS Backup**: A service that centrally manages policy-based backups across many AWS services.
- **AWS Billing Conductor**: A service that creates pro-forma bills at custom rates for billing groups without changing the actual AWS charges.
- **AWS Budgets**: A service that tracks cost, usage, or commitment thresholds and alerts you on actual or forecasted values.
- **AWS Certificate Manager (ACM)**: Issues and renews TLS certificates used by load balancers and CloudFront for HTTPS.
- **AWS CLI**: A command-line tool that controls AWS services from a terminal and can be scripted.
- **AWS Cloud Adoption Framework (AWS CAF)**: AWS guidance for planning a cloud transformation through six perspectives and four benefit categories.
- **AWS CloudFormation**: The AWS IaC service that provisions resources declared in a JSON or YAML template as a single stack.
- **AWS CloudHSM**: Dedicated, single-tenant hardware security modules for storing keys under strict regulatory requirements.
- **AWS CloudTrail**: Logs API calls and account activity, recording which identity did what, when, and from which IP address.
- **AWS Config**: Tracks how resource configurations change over time and flags any that break rules you define.
- **AWS Cost and Usage Report (CUR)**: The most detailed AWS billing data, with per-resource, per-hour line items delivered to an S3 bucket.
- **AWS Cost Explorer**: An interactive tool for charting, filtering, and forecasting your historical AWS spend.
- **AWS Database Migration Service (AWS DMS)**: A service that migrates databases to AWS with continuous replication so the source stays live until cutover.
- **AWS Direct Connect**: A dedicated private physical network link between your facility and AWS that avoids the public internet.
- **AWS DMS**: A service that migrates and replicates database data while the source stays online.
- **AWS Elastic Beanstalk**: A platform service that deploys uploaded application code and builds the underlying infrastructure for you.
- **AWS Fargate**: A serverless engine that runs ECS or EKS containers without any instances to manage.
- **AWS Global Accelerator**: A service that gives an application static IP addresses and carries its TCP/UDP traffic over the AWS network.
- **AWS Glue**: A serverless ETL service that also maintains a data catalog.
- **AWS Health API**: Programmatic access to your account's health events, available with Business Support or higher.
- **AWS Health Dashboard**: A view of AWS service status and of events or maintenance that affect your own resources.
- **AWS IAM (Identity and Access Management)**: The free, global service that controls who can sign in to an AWS account and what they are allowed to do.
- **AWS IAM Identity Center**: Central single sign-on that gives workforce users access to multiple AWS accounts and applications from one portal.
- **AWS IoT Core**: A service that connects devices securely to AWS and routes their data.
- **AWS KMS (Key Management Service)**: The managed service that creates and controls encryption keys and powers at-rest encryption across many AWS services.
- **AWS Lambda**: Serverless compute that runs short functions in response to events and bills per request and compute time.
- **AWS Local Zone**: An extension of a Region that places compute and storage in a metro area for very low latency to local users.
- **AWS Management Console**: The browser-based graphical interface for working with AWS by hand.
- **AWS Marketplace**: A catalog of third-party software, including security products, billed through your AWS account.
- **AWS Migration Hub**: A central place to discover servers, plan migrations, and track their progress.
- **AWS Outposts**: AWS infrastructure and services installed in your own data center.
- **AWS Partner Network (APN)**: The program for ISVs and system integrators that build solutions and deliver services on AWS.
- **AWS Prescriptive Guidance**: A library of proven strategies, guides, and patterns for planning migrations and modernization.
- **AWS Pricing Calculator**: A free web tool that estimates the cost of a planned architecture without needing an AWS account.
- **AWS Professional Services**: AWS's paid consulting organization that delivers large projects such as migrations for enterprises.
- **AWS re:Post**: The official community Q&A site that replaced AWS Forums and also hosts the Knowledge Center.
- **AWS Schema Conversion Tool (AWS SCT)**: A tool that converts a database schema and code from one engine to another for heterogeneous migrations.
- **AWS SCT**: A tool that converts database schemas and code from one engine to another.
- **AWS SDK**: A language-specific library that lets application code call AWS APIs.
- **AWS Secrets Manager**: Stores secrets such as database passwords encrypted and can rotate them automatically.
- **AWS Security Hub**: Collects findings from AWS and partner security tools into one dashboard and checks accounts against best-practice standards.
- **AWS Shield**: DDoS protection, with a free, automatic Standard tier and a paid Advanced tier that adds expert response support.
- **AWS Site-to-Site VPN**: An IPsec-encrypted tunnel over the internet between an on-premises network and AWS.
- **AWS Snowball**: A rugged physical device AWS ships to you for moving large amounts of data offline into Amazon S3.
- **AWS Step Functions**: A service that coordinates multi-step workflows as visual state machines.
- **AWS Storage Gateway**: A hybrid service that gives on-premises applications access to AWS storage with local caching.
- **AWS Trust & Safety team**: The AWS group that investigates reports of AWS resources being used for spam, attacks, or malware.
- **AWS Trusted Advisor**: Checks an account against AWS best practices and flags issues such as open security groups and a root user without MFA.
- **AWS WAF**: A web application firewall that inspects HTTP(S) requests to block attacks such as SQL injection and cross-site scripting.
- **AWS Wavelength Zone**: AWS compute and storage embedded in a telecom carrier's 5G network for ultra-low-latency mobile apps.
- **AWS Well-Architected Framework**: AWS guidance for designing good cloud workloads, organized into six pillars.
- **AWS Well-Architected Tool**: A free console service that reviews a workload against the framework and produces an improvement plan.
- **AWS X-Ray**: A distributed tracing service that follows requests through an application to find errors and latency.

## B

- **Bring Your Own License (BYOL)**: Using software licenses you already own on AWS, while you remain responsible for compliance.

## C

- **CAF perspective**: One of six capability areas (Business, People, Governance, Platform, Security, Operations) an organization develops to adopt the cloud.
- **Capital expenditure (CapEx)**: Money spent up front on assets you own, such as servers, that depreciate whether or not you use them.
- **Compute Savings Plan**: The most flexible Savings Plan, covering any EC2 family, size, or Region as well as Fargate and Lambda.
- **Consolidated billing**: The AWS Organizations feature that combines all member accounts into one bill with pooled usage and shared discounts.
- **Convertible Reserved Instance**: An RI with a smaller discount that you can exchange for a different family, OS, or tenancy during its term.
- **Cost allocation tag**: A key-value label that, once activated in the Billing console, breaks out costs by project, team, or environment.

## D

- **Data sovereignty**: A requirement that data stay within a specific country or jurisdiction, met on AWS by choosing the Region.
- **Dedicated Host**: A physical server assigned to your account, with socket and core visibility for license-bound software.
- **Dedicated Instance**: An instance on hardware that no other AWS customer uses, without visibility into or control of the host.

## E

- **EC2 Instance Savings Plan**: A Savings Plan locked to one instance family in one Region in exchange for a larger discount.
- **Economies of scale**: AWS's lower unit costs from combining usage across many customers, passed on as lower prices.
- **Edge location**: A site close to end users that caches and delivers content, used by Amazon CloudFront.
- **Elastic Load Balancing (ELB)**: A service that spreads incoming traffic across healthy targets in one or more Availability Zones.
- **Elasticity**: Automatically adding resources when demand rises and releasing them when it falls.
- **Encryption at rest**: Protection for stored data, so it cannot be read without the keys even if the storage itself is accessed.
- **Encryption in transit**: Protection for data moving across a network, usually through TLS/HTTPS.

## F

- **Federated identity**: Signing in with an external identity provider and receiving temporary AWS credentials through a role, without an IAM user.

## H

- **High availability**: Designing a workload to keep running with minimal disruption when components fail.
- **Hybrid deployment**: A setup where AWS resources and on-premises infrastructure are connected and operate together.

## I

- **IAM group**: A set of IAM users that share the permissions attached to the group.
- **IAM policy**: A JSON document that allows or denies specific actions, attached to an identity or to a resource.
- **IAM role**: An identity that people, services, or external users assume to get temporary credentials, with no password or access keys of its own.
- **IAM user**: An identity with long-term credentials that represents one person or one application.
- **Infrastructure as code (IaC)**: Defining infrastructure in machine-readable files rather than creating it manually.
- **Instance store**: Temporary block storage on the host's physical disks that is lost when the instance stops or terminates.
- **Internet gateway**: A VPC component that allows two-way traffic between the VPC and the internet.

## L

- **License-included**: Pricing where the software license cost is bundled into the AWS resource's hourly rate.

## M

- **Managed service**: A service where AWS runs the infrastructure and routine operations such as patching, backups, and failover.
- **Multi-AZ deployment**: An RDS option that keeps a standby in another AZ and fails over to it automatically.
- **Multi-factor authentication (MFA)**: A second sign-in factor, such as a one-time code or a security key, that is required in addition to a password.

## N

- **NAT gateway**: A component that lets resources in private subnets start outbound internet connections while blocking inbound ones.
- **Network ACL**: A stateless subnet-level filter with numbered allow and deny rules, where the first matching rule wins.

## O

- **On-Demand Capacity Reservation**: Guaranteed EC2 capacity in a chosen Availability Zone for any duration, with no discount by itself.
- **On-Demand Instances**: EC2 capacity billed at the standard rate only while it runs, with no commitment.
- **Operational expenditure (OpEx)**: Ongoing, pay-as-you-go spending on what you actually consume.

## P

- **Principle of least privilege**: The practice of granting each identity only the permissions its task requires.

## R

- **Read replica**: A read-only copy of a database used to offload read traffic from the primary.
- **Refactor**: Re-architecting an application to be cloud-native.
- **Region**: A geographic area of AWS infrastructure that contains multiple isolated Availability Zones.
- **Rehost**: Moving an application to AWS unchanged, often called lift and shift.
- **Replatform**: Moving an application with small optimizations, such as switching to a managed database, without redesigning it.
- **Reserved Instance (RI)**: A one- or three-year billing discount that applies automatically to running instances with matching attributes.
- **Rightsizing**: Continuously matching resource types and sizes to what a workload actually needs.
- **Root user**: The identity created with the account's email address, which has unrestricted access that IAM policies cannot limit.

## S

- **S3 Intelligent-Tiering**: An S3 storage class that moves objects between access tiers automatically when usage patterns are unknown.
- **S3 lifecycle policy**: A bucket rule that shifts aging objects into lower-cost storage classes and can later delete them.
- **Savings Plans**: A one- or three-year commitment to a set hourly amount of compute spend, billed at a discounted rate.
- **Scalability**: A system's ability to grow, vertically or horizontally, to handle more load.
- **Security group**: A stateful, allow-only virtual firewall attached to an instance's network interface.
- **Shared control**: A control that AWS and the customer each perform at their own layer: patch management, configuration management, and awareness and training.
- **Shared responsibility model**: AWS secures the infrastructure that runs its services, and the customer secures what they build, store, and configure on top of it.
- **Spot Instances**: Spare EC2 capacity sold at a steep discount that AWS can reclaim after a two-minute warning.
- **Standard Reserved Instance**: The RI class with the deepest discount, whose instance family and OS cannot be changed.
- **Storage tier**: A storage class that trades a lower per-GB-month rate for higher retrieval costs as data gets colder.
- **Subnet**: A range of IP addresses within a VPC that lives in exactly one Availability Zone.
- **Sustainability pillar**: The sixth Well-Architected pillar, focused on reducing the environmental impact of workloads.
- **Systems Manager Parameter Store**: A store for configuration values and encrypted secure strings, without built-in automatic rotation.

## T

- **Technical Account Manager (TAM)**: An AWS contact who guides your operations over time, shared in Enterprise On-Ramp and designated in Enterprise.
- **Total cost of ownership (TCO)**: The full lifetime cost of running a workload, including facilities, power, cooling, licenses, and staff as well as hardware.

## V

- **VPC Flow Logs**: Records of accepted and rejected network traffic for interfaces in a VPC, sent to CloudWatch Logs or S3.
